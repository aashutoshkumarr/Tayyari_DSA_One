## 📚 Curriculum & Module Navigation

This repository is an end-to-end algorithmic problem-solving repository designed for FAANG / Tier-1 engineering interview preparation. Every module is cleanly separated with clean, idiomatic Java implementations.

### 🗂️ Core Topics & Directory Structure

| Module | Core Concepts & Problems Implemented |
| :--- | :--- |
| **`Arrays`** | Dynamic sizing, Prefix Sum, Two Pointers, Sliding Window, Dutch National Flag, Missing Number. |
| **`2D_Arrays`** | Matrix transposition, Spiral Traversal, Search in 2D Sorted Matrix, Matrix Rotation. |
| **`Strings`** | String matching, Palindromes, Anagrams, Rolling Hash, Longest Substring Without Repeating Characters. |
| **`BinarySearch`** | Standard Search, Search in Rotated Sorted Array, Peak Element, Allocation of Minimum Pages, Aggressive Cows. |
| **`LinkedList`** | Singly & Doubly Linked Lists, Cycle Detection (Floyd's Tortoise & Hare), Reversal, Merge K Sorted Lists. |
| **`Stacks` & `Queues`** | Monotonic Stack, Next Greater Element, Largest Rectangle in Histogram, Min Stack, Circular Queue. |
| **`Deque`** | Sliding Window Maximum, Monotonic Deque, Palindrome Checking. |
| **`BinaryTrees`** | BFS/DFS traversals (Inorder, Preorder, Postorder), Diameter, Height, LCA, Boundary & Top View. |
| **`BST`** | Insertion, Deletion, Search, Validation of BST, Inorder Successor, Kth Smallest Element. |
| **`Heaps`** | Min/Max Heap implementation, Top-K Frequent Elements, Median in a Data Stream, Kth Largest Element. |
| **`Recursion` & `Backtracking`** | N-Queens, Sudoku Solver, Subsets, Permutations, Combination Sum, Rat in a Maze. |
| **`DP (Dynamic Programming)`** | 0/1 Knapsack, Longest Common Subsequence (LCS), LIS, Matrix Chain Multiplication, DP on Grids. |
| **`Graphs`** | BFS, DFS, Dijkstra's Algorithm, Bellman-Ford, Prim's & Kruskal's MST, Topological Sort (Kahn's), DSU. |
| **`Greedy`** | Activity Selection, Fractional Knapsack, Job Sequencing, Huffman Coding. |
| **`Bit_Manipulation`** | Bit masks, Power of Two, Single Number detection, Count Set Bits, Fast Exponentiation. |
| **`Cyclic_Sort`** | Missing Number, Find All Duplicates, Set Mismatch, First Missing Positive ($O(N)$ In-Place). |
| **`PrefixSum_Seive`** | Sieve of Eratosthenes, Segmented Sieve, Range Sum Queries ($O(1)$ lookup). |
| **`SpecialAlgos`** | Kadane's Algorithm, Boyer-Moore Voting Algorithm, Two Pointer Optimizations. |
| **`OOPS`** | Inheritance, Polymorphism, Abstraction, Encapsulation, Interface Design patterns. |

## ⚡ Algorithmic Complexity Reference

```
  ┌────────────────────────┬─────────────────────┬─────────────────────┐
  │ Data Structure         │ Average Time        │ Worst Time (Access) │
  ├────────────────────────┼─────────────────────┼─────────────────────┤
  │ Array / ArrayList      │ O(1) Access         │ O(N) Search/Insert  │
  │ Stack / Queue          │ O(1) Push/Pop       │ O(N) Search         │
  │ Binary Search Tree     │ O(log N) Search     │ O(N) (Unbalanced)   │
  │ Heap / Priority Queue  │ O(1) Peek, O(log N) │ O(log N) Pop        │
  │ Hash Map / Set         │ O(1) Lookups        │ O(N) Hash Collision │
  └────────────────────────┴─────────────────────┴─────────────────────┘
```
